Tool Map

Most tools on this site are self-contained. Some are not: they hand data to each other through your browser's storage, share an engine, or at least know of each other's existence. This map shows every connection that actually moves data, and a few that merely point. Hover a tool to see its neighbourhood; click to open it. None of these arrows touch a server.

data handoff (moves your file or setting) shared engine (same code, same cached model) link (points, carries nothing)

A labelled box like alber.palette.v1 is a storage slot in your browser: one tool writes it, several tools read it, and it survives until overwritten.

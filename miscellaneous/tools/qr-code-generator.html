QR Code Generator

A QR code generator that wants nothing from you. No account, no upload, no shortener sitting between the code and its destination. The encoder is written into this page, so the symbol on screen is built from your text and nothing else.

  • Free foreground and background colours, with a transparent background as the default, exported as PNG or SVG.
  • The error-correction slider is the interesting control, so the tool shows what it does: which modules carry your data and which carry redundancy.
  • Cover part of the symbol and the tool counts damaged codewords against the actual correction budget, instead of quoting the usual marketing percentage.
  • Six module shapes, from plain squares to a tangle that joins neighbouring modules at random without ever closing a loop. Each carries the resolution it costs, measured against an independent decoder rather than asserted.
  • Presets for WiFi credentials, contact cards, email, SMS, geo coordinates and phone numbers.

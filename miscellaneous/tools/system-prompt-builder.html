System Prompt Builder

Click together a personal system prompt for your chatbot: pick one variant per aspect or leave it out, edit any building block, and copy the result as Markdown into Claude, ChatGPT or an API call.

  • Ten aspects: communication style, honesty and pushback, your background, code preferences, how to handle short input, facts and sources, creativity, response format, typography, meta rules.
  • Every aspect offers two or three pre-written variants plus the option to leave it out entirely; sensible defaults give you a working prompt on first load.
  • Each generated paragraph can be edited in place before copying, so the template becomes your own text.
  • The prompt is generated in English or German, independent of the interface language, and works in any chatbot that accepts custom instructions.
